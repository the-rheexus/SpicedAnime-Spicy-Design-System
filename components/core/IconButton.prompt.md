Square icon-only button for toolbars, top-bar actions, and table row actions. Always give it a `label` for accessibility + tooltip.

```jsx
<IconButton icon="bell" label="Notifications" />
<IconButton icon="more-horizontal" label="Row actions" size="sm" />
<IconButton icon="filter" label="Filters" active />
```

Variants: `ghost` (default) / `solid`. `active` gives the spice-tinted selected state.
